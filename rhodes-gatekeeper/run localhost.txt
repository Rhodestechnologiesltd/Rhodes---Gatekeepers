Until the server is ready, **keep your laptop awake and connect the iPad to the same Wi-Fi**.

Each time you want to use Gatekeeper, open **VS Code** and start **two separate Command Prompt terminals**.

**Terminal 1 — start the backend:**

```cmd
cd /d C:\Users\ZakiyyahArab\Downloads\rhodes-gatekeeper-v2\rhodes-gatekeeper
npm run dev:server
```

Wait for **“Rhodes Gatekeeper listening.”** Leave this terminal running.

**Terminal 2 — start the website:**

```cmd
cd /d C:\Users\ZakiyyahArab\Downloads\rhodes-gatekeeper-v2\rhodes-gatekeeper
npm run dev:web
```

Leave this terminal running too.

Then:

- **Laptop website:** open [http://localhost:5173](http://localhost:5173). Sign in as `admin`.
- **iPad application:** tap the installed **Rhodes Gatekeeper version 2** icon. Sign in as `guard`.

Both demo accounts use **`Gatekeeper-Demo-2026`**.

**You don’t need Android Studio, Expo, another build, or another enrolment code each time.** The iPad remembers its connection.

If the iPad stops connecting after changing Wi-Fi, run `ipconfig` on the laptop and check whether its IPv4 address is still **`192.168.100.205`**. Don’t run `npm run seed` again during normal startup.
